# E-Commerce Sales & Customer Performance Dashboard

An end-to-end analytics project using **MySQL, Power BI, and DAX** to explore e-commerce revenue, profitability, product performance, and customer trends.

## Project Files

- `ecommerce_dashboard_project/` — complete project folder, including SQL, Power BI, data, and documentation.

## Dashboard Preview

See the dashboard screenshot and full project documentation inside the project folder.

**Dataset:** 3,200 rows of synthetic data created for portfolio demonstration; not real company data.

**Tools:** MySQL, Power BI Desktop, DAX, CSV.
